IMPORTCELL MOBILE — CONHEÇA O APLICATIVO

Bem-vindo à ImportCell Mobile.

Este projeto foi desenvolvido para apresentar a experiência de uma loja de celulares também no Android. A ideia é permitir que o usuário consulte os aparelhos disponíveis e acompanhe uma compra de forma simples, pelo próprio aplicativo.

COMO O APLICATIVO FUNCIONA?

Ao abrir a ImportCell, o usuário encontra o catálogo de smartphones. É possível conferir os modelos, os preços e os detalhes de cada aparelho, além de escolher opções como cor e armazenamento.

Para fazer um pedido, basta criar uma conta, entrar no aplicativo, selecionar o celular desejado e adicioná-lo ao carrinho. Depois, o usuário informa os dados de entrega e escolhe uma forma de pagamento demonstrativa. Também há uma área para consultar os pedidos e solicitar o cancelamento quando essa opção estiver disponível.

As compras são apenas uma simulação acadêmica. Nenhum pagamento real é realizado.

O QUE É IMPORTANTE SABER?

O aplicativo precisa estar conectado ao servidor da ImportCell, responsável pelos produtos, cadastros e pedidos. Por isso, abrir o aplicativo sem o servidor pode não ser suficiente para usar todas as funções.

O projeto foi preparado para Android, mas o arquivo entregue contém o código do aplicativo, e não um instalador pronto para tocar e abrir no celular. Para colocá-lo em funcionamento, é necessário configurar o ambiente Android e a conexão com o servidor.

O pacote também inclui o código do servidor em C#. Essa versão utiliza SQL Server e é diferente da versão portátil para computador, preparada separadamente com SQLite.

O QUE TEM DENTRO DA PASTA?

- ImportCell_App: arquivos do aplicativo Android e sua interface.
- ImportCell_Final: código do servidor que atende o aplicativo.

Os arquivos podem ser consultados por quem quiser conhecer como o projeto foi desenvolvido. Para compilar e executar o aplicativo no Android, são necessárias ferramentas de desenvolvimento, como Android Studio e Node.js, além do servidor configurado.

O projeto inclui a integração visual com o VLibras, um recurso de acessibilidade que depende de conexão com a internet para utilizar seus serviços.

OBSERVAÇÃO SOBRE OS TESTES

Esta versão mobile foi analisada pelos arquivos do projeto, mas ainda não teve seu funcionamento completo confirmado em um celular ou emulador Android. A versão do computador foi testada separadamente.
