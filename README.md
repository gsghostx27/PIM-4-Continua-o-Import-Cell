 Este trabalho apresenta a continuação do Projeto Integrado Multidisciplinar (PIM) III, no qual foi idealizada a ImportCell, uma loja virtual fictícia de smartphones importados. 
  O protótipo anterior guardava usuários e pedidos apenas no navegador. A versão desenvolvida neste semestre adota uma arquitetura integrada: uma API REST em ASP.NET Core 8, com Entity Framework Core e banco de dados relacional SQL Server, autenticação por JSON Web Token (JWT), perfis de acesso de cliente e administrador, controle transacional de estoque e uma interface web responsiva servida pela própria aplicação. 
  O documento caracteriza a organização, planeja a solução tecnológica, propõe ações de responsabilidade social, diversidade e acessibilidade, descreve o desenvolvimento web, o projeto da aplicação móvel que consome a mesma API, a arquitetura de software orientada a objetos, o projeto do banco de dados com modelo lógico, modelo físico, procedures e triggers, o plano de infraestrutura em nuvem com práticas de DevOps e o planejamento ágil baseado em Scrum e Kanban. 
  O resultado é uma proposta completa de modernização tecnológica, na qual os pagamentos são apenas simulados e a proteção dos dados do cliente é tratada desde o projeto.
